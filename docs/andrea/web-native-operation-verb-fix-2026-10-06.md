## Native correction

`web_native_operation_verb.py` refines only simple positive action-led source
units beginning with `control`. This narrow recognizer excludes narrative,
negated, conditional and compound fragments; it is not a general action parser.
It uses source content, not page URLs, passage number 11, expected output text
or a hard-coded asyncio object. Capability evidence eligibility stays as in v8.

For a recognized own source unit, the native text branch starts with either
`Permette di controllare ` or `Consente di controllare `. The model writes the
complement and selects its own passages. This is an explicit constraint on the
main verb, not a text enum containing complete expected answers. The object,
whole sentence, number of claims and missing-answer array are not injected.
Other operation branches are unchanged. When a source requires an identifier
prefix such as `IPC: `, that prefix remains before the control verb.

The verb precedes all free text, avoiding an unbounded wildcard before a
mandatory term. The pattern uses no lookahead, backreference or new character
cap. It composes with the known previous fixed-name or leading-label patterns;
unknown prior patterns fail closed instead of being replaced silently. Original
source bytes, numbering, selected context and question remain unchanged.

The adapter applies the same source-verb policy to both comparison variants.
Their native schema hashes explicitly change. CSV and missing-price messages
and schemas remain byte-for-byte v8; the original question still closes the
user message after metadata. The reference is an archived full-context base,
not the currently installed v1 prompt. New comparisons must include the cost
of the added prompt metadata and common grammar, using freshly measured times.

All existing source, type, condition, mechanism, performance, label, relevance
and operation/example checks remain. A control starter alone cannot certify
that its generated object or free tail is true. For example, a tail adding
external-command execution is still refused by the existing guard, even after
a permitted control starter. General entailment and negation remain review
criteria. No output is repaired, re-anchored, shortened or dropped. A detected
error refuses the whole answer and preserves raw text and prior checks in the
report; this refusal remains a failed model test.
