   event-loop/networking/subprocess/OS-signals catalogue, with `I/O: `. That
   source unit does not contain I/O. The original v4 grammar has an unconstrained

   a faithful subprocess-only partial point may omit the neighboring signals

## Separate generation constraints and the finite alias correction

`web_source_label_scope.py` operates after the frozen v4 positive name-prefix
adapter. It groups each native branch by its own permitted identifiers, using
only its quote's literal names, existing API/IO aliases and the new literal
CSV-file alias. An ordinary branch receives a regular-language guard against
known leading labels whose names are absent from that own source. Mandatory
branches retain their own existing positive labels. Conditional OS names are
not made mandatory, neighboring names are not added and eligible references,
source bytes, original questions and array budgets stay unchanged.

The foreign-label guard is a finite prefix trie expressed through supported
anchored alternation and character classes. A mismatch permits ordinary prose;
completion of a forbidden label has no continuation. Initial ASCII spaces
cannot bypass that trie. There is no unsupported negative lookahead, deferred
positive identifier obligation, native hard string cap, model retry or output
repair. The guard rejects the actual `I/O:` and `REPL:` misattributed starts
before generation. A source-license test is still required after generation.

This is explicitly a guard for known leading labels, not a general meaning
classifier. Identifiers placed elsewhere, unknown labels, spelling variations
and incorrect predicates still require the existing source checks and review.
Correct copied names do not establish semantic entailment. No every-future-output
or guaranteed-latency claim is made.

The CSV correction augments `source_identifier_aliases` only on a separately
constructed experimental contract module. The original contract is loaded
separately for diagnostic replay. `CSV` is optionally licensed only by literal
lower-case `csv file` or `file csv` in that same source unit. A namespace such
as `csv.reader`, file extension, another unit or unrelated acronym cannot
license this alias. It is not global case folding and it does not create a new
mandatory identifier. All checks on conditions, unquoted fields, exact float
type, other names, cardinality, source scope and stream completeness are rerun
on the original unmodified response. Both `originalApplicationChecks` and the
explicit `finiteAliasApplicationChecks` are reported before new constraints.

For the own one-statement `often a perfect fit` source, the existing literal
name prefix is followed immediately by `spesso ` before the free predicate.
That is a source-derived frequency qualifier in the generation format, not a
full generated predicate. A separate narrow application guard refuses an
universal `sempre`/`always` upgrade and a perfection assertion that drops
`often`/`spesso`. This explicitly adds a source qualification check; it does
not relabel historical automatic verdicts or lower acceptance criteria.
